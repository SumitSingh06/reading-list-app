# Reading List App

A simple, responsive Reading List web application for students. Add books, track their reading status, filter the list, and see a quick summary.

**Deployed link:** ADD_YOUR_VERCEL_LINK_HERE

## Features
- Add a book with a title and a reading status (Want to Read, Reading, Finished)
- Change a book's status at any time
- Filter books by status
- Delete an individual book
- Summary section showing Total Books, Currently Reading and Finished counts
- Friendly message when the list is empty: "Your reading list is empty. Add your first book."
- Duplicate titles are blocked (ignoring upper/lower case and extra spaces)
- Book titles are limited to 60 characters
- Data is stored in the browser only (localStorage) — no login, payments, external APIs or cloud database
- Clean layout for desktop and mobile

## Technologies
HTML, CSS, JavaScript

## Run locally
Open `index.html` in a web browser.
